方法与复现

两种引擎分别采样。4 轮 Latin 轮换，各实现使用同轮相同页面顺序；12 轮 CLI 同样平衡轮换。保留所有原始样本及离群值，不强制 GC。JavaScript 在计时外让出事件循环完成 jsdom 清理；Python 按正常引用计数/GC运行。四种实现各自使用原生 JSON 输出路径，UTF-8 字节数在计时外计算。

诊断在实际公开 Python 函数内替换一次私有 native 调用为计时入口，保持提取与结果不变。其边界残差是估计值；Python 解析/Article 阶段还包含观察回调返回的少量工作。阶段总和按每次样本检查。单独的未插桩正式测量才用于速度排名。Python/Rust 跨进程差值受运行时、缓存和分配器影响，不能全部归因为绑定。
