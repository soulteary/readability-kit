测量范围、限制与复现命令

常驻进程串行执行，各实现采用默认运行时参数，不强制 GC。JavaScript 在计时外让出事件循环，以完成 jsdom 排队的释放任务。JS JSON.stringify 生成 UTF-16 字符串，Go/Rust 原生 JSON 序列化生成 UTF-8 字节；这是各自原生序列化成本，并非完全相同的字节输出指令。

RSS 由 Python wait4 记录子进程高水位：macOS 字节、Linux KiB 转为字节。驱动进程不计入。内存与耗时均为此机器、此版本、单请求串行负载的测量，未控制热状态、频率和其他系统任务。常驻顺序完全轮换，9 轮 CLI 顺序近似平衡。小样本只报告中位数和范围。
